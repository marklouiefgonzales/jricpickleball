# J-Ric Pickleball DXB

Static website, ready for GitHub Pages.

## Publish
1. Create a repo and upload everything in this folder (keep `index.html` at the top level).
2. Repo **Settings > Pages > Deploy from a branch > main / (root)**.

## Customize
- Business info, prices, address, phone, email: `index.html` (search for `example.com`, `Dubai address`, `+971 50`).
- Colors: top of `css/style.css` (`:root`).
- Message form: create a free form at formspree.io and replace `YOUR_FORM_ID` in `index.html`. Also change `hello@example.com` in `js/main.js`.
